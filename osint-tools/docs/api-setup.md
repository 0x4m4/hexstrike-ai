# API Setup Guide

## Supported APIs

### Shodan
- URL: https://shodan.io/
- Add to: SHODAN_API_KEY

### Hunter.io
- URL: https://hunter.io/
- Add to: HUNTER_API_KEY

### HaveIBeenPwned
- URL: https://haveibeenpwned.com/API/Key
- Add to: HIBP_API_KEY

### Censys
- URL: https://censys.io/
- Add to: CENSYS_API_ID, CENSYS_API_SECRET

### SecurityTrails
- URL: https://securitytrails.com/
- Add to: SECURITYTRAILS_API_KEY

### IntelX
- URL: https://intelx.io/
- Add to: INTELX_API_KEY

### DeHashed
- URL: https://dehashed.com/
- Add to: DEHASHED_API_KEY, DEHASHED_EMAIL
